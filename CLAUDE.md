# Project instructions

## Website work
For any task that builds, designs, redesigns or polishes a website, landing page, or frontend UI (including the FocusFlow planner site), load the `elite-web-design` skill first and follow it together with `references/master-brief.md`. It routes to the other installed skills: `frontend-design`, `ui-ux-pro-max`, the `gsap-*` skills, and `webapp-testing`.
